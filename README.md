# 40k Redux

This is my take on the rules of 40k, using 11th edition as a base. This readme aims to include all core rules changes, otherwise use the originals. Some may be subject to change based on feedback as well as when I get to some factions that might require it. I'm very slowly getting through all the factions haha. My Discord is kenzie1302 for any queries, questions, suggestions, and feedback.

# Core Rules Changes

### Major

- Full revamp of unit characteristics to decrease lethality and limit games becoming lopsided too quickly.
- Much more customisation through unlocked model numbers, as well as new wargear options for each unit type.
- Lethal Hits and Sustained Hits are replaced by Critical: X. When an unmodified hit roll of 6 is scored, follow the added effect "X".
- Advance rolls are now D3 rather than D6.
- All Ranged weapons can be fired in engagement range, but when doing so they use Snap Shooting if the attacking unit is both in engagement range of an infantry, swarm, or beast model and not a vehicle/monster. Melee weapons have the Melee keyword which removes this penalty.

### Minor

- Jump Packs are now an activated ability that adds 3" of movement per turn up to 3 times.
- Take to the skies only costs 1" for non-Monster/Vehicle units with Fly, and every model in the unit must have the Fly keyword.
- Things are generally more expensive.
- You can have up to 6 of each Battleline unit, up to 2 of each Elite unit, and up to 3 of each Vehicle/Monster unit. Some detachments increase this limit for certain unit types.
- AP is now a positive number and +AP increases the penalty to armour saves and -AP decreases it.
